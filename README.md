# India Election Result 2024 Analysis

## 📊 Project Overview

This project analyzes the **2024 Indian General Election (Lok Sabha Election)** using data analytics and visualization techniques.

The objective is to transform election-result data into meaningful insights about **political party performance, state-wise results, constituency-level outcomes, voter turnout, and vote distribution**.

The analysis was developed using **Microsoft Power BI**, with a focus on data cleaning, data modeling, DAX calculations, and interactive dashboard development.

The project uses election data published by the **Election Commission of India (ECI)**.

---

## 🎯 Project Objectives

The main objectives of this analysis are to:

* Analyze overall election results.
* Compare the performance of major political parties.
* Analyze party performance across different states.
* Identify states where parties performed strongly or weakly.
* Analyze constituency-level election results.
* Examine vote distribution and winning margins.
* Analyze voter turnout across states.
* Identify important patterns and trends in the election data.
* Build an interactive Power BI dashboard for exploring the results.

## 📈 Power BI Dashboard

The Power BI dashboard provides an interactive view of the 2024 Indian General Election results.

### Key Dashboard Areas

#### 1. Election Overview

Provides a high-level summary of the election through KPIs and visualizations.

Possible metrics include:

* Total Seats
* Total Parties
* Total Candidates
* Total Votes
* Winning Seats
* Voter Turnout

#### 2. Party Performance

Analyzes the performance of political parties based on:

* Seats Won
* Votes Received
* Vote Share
* State-wise Performance
* Constituency Performance

#### 3. State-wise Analysis

Allows users to compare election results across Indian states.

The analysis can be used to identify:

* Highest-performing parties by state
* Seat distribution
* Vote distribution
* State-wise voter turnout
* Party dominance across regions

#### 4. Constituency Analysis

Provides a more detailed view of individual constituencies, including:

* Winning candidate
* Winning party
* Votes received
* Runner-up
* Vote margin
* Constituency-level results

#### 5. Voter Turnout Analysis

Analyzes voter participation across states and constituencies.

This helps identify differences in electoral participation between regions.

## 🔍 Key Business Questions

The dashboard was designed to answer questions such as:

1. Which political parties won the most seats?
2. Which states contributed the highest number of seats to each major party?
3. Which states had the highest voter turnout?
4. Which constituencies had the closest contests?
5. Which candidates won with the largest vote margins?
6. How were seats distributed among political parties?
7. How did vote share compare with seats won?
8. Which parties performed strongly in particular states?
9. Which states had relatively high or low voter participation?
10. What patterns can be observed from the constituency-level results?

## 💡 Key Insights

The analysis helps uncover patterns in India's 2024 Lok Sabha election results, including:

* Differences between **vote share and seat share**.
* Strong regional variations in party performance.
* Significant differences in voter turnout between states.
* Constituencies with particularly narrow or large winning margins.
* Concentration of party performance in specific geographical regions.
* Differences between national-level and state-level election performance.

The official Election Commission of India statistical reports provide detailed constituency-wise, state-wise and party-wise election data that can be used to validate these findings.
